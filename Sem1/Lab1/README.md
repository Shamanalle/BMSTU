## Часть 1. Операторы цикла

### Условие задачи

Вывести на печать пять первых слагаемых суммы

$$S = \sum_{n=1}^{\infty} \frac{1}{2^n}$$

и сумму этих слагаемых.

### Решение

Каждое следующее слагаемое в 2 раза меньше предыдущего, поэтому оно вычисляется по рекуррентной формуле $a_{n+1} = a_n / 2$, $a_1 = 1/2$. Так не нужно считать степень двойки на каждой итерации.

По условию работы задача решена тремя видами цикла:

- **`while`** (с предусловием): условие `n <= 5` проверяется до выполнения тела цикла;
- **`do-while`** (с постусловием): тело выполняется хотя бы один раз, условие проверяется после него;
- **`for`**: инициализация, условие и изменение параметров (`n++, a /= 2`) записаны в заголовке цикла.

**Выбор вида цикла.** Число повторений заранее известно (5), поэтому лучше всего подходит цикл `for`: весь закон изменения счётчика виден в одной строке. Циклы `while` и `do-while` удобнее, когда число повторений заранее неизвестно, например при суммировании ряда до заданной точности.

### Листинг программы

См. [part1_series.cpp](part1_series.cpp).

### Результат работы программы

```
1) while:
  a1 = 1/2^1 = 0.50000
  a2 = 1/2^2 = 0.25000
  a3 = 1/2^3 = 0.12500
  a4 = 1/2^4 = 0.06250
  a5 = 1/2^5 = 0.03125
  Sum = 0.96875

2) do-while:
  a1 = 1/2^1 = 0.50000
  ...
  Sum = 0.96875

3) for:
  a1 = 1/2^1 = 0.50000
  ...
  Sum = 0.96875

Check: 1 - 1/2^5 = 31/32 = 0.96875
Sum of infinite series = 1
```

### Ручной расчёт

$$\frac{1}{2} + \frac{1}{4} + \frac{1}{8} + \frac{1}{16} + \frac{1}{32} = \frac{16 + 8 + 4 + 2 + 1}{32} = \frac{31}{32} = 0.96875$$

Проверка по формуле суммы геометрической прогрессии: $S_5 = \frac{b_1 (1 - q^5)}{1 - q} = \frac{0.5 \cdot (1 - 1/32)}{0.5} = 1 - \frac{1}{32} = 0.96875$.

Точная сумма бесконечного ряда: $\frac{1/2}{1 - 1/2} = 1$.

Результаты программы совпадают с ручным расчётом во всех трёх вариантах цикла.

## Часть 2. Массивы и структуры

### Тренировочная задача

```cpp
struct Test
{
    short b;       // 2 байта
    int a;         // 4 байта
    char ch1, ch2; // 1 + 1 байт
};
```

`sizeof(Test)` равен 12, хотя сумма размеров полей 2 + 4 + 1 + 1 = 8 байт.

**Причина — выравнивание.** Компилятор размещает каждое поле по адресу, кратному его размеру: `int` должен начинаться с адреса, кратного 4. Кроме того, размер всей структуры округляется до кратного самому строгому выравниванию (4 байта), чтобы в массиве структур каждый элемент тоже был выровнен.

| Смещение | 0–1 | 2–3 | 4–7 | 8 | 9 | 10–11 |
|---|---|---|---|---|---|---|
| Поле | `b` | *пусто* | `a` | `ch1` | `ch2` | *пусто* |

**Исправление:** расположить поля по убыванию размера, тогда пустые байты не нужны:

```cpp
struct Test2
{
    int a;         // смещение 0
    short b;       // смещение 4
    char ch1, ch2; // смещения 6 и 7
};                 // sizeof(Test2) == 8
```

Вывод программы [part2_struct_size.cpp](part2_struct_size.cpp):

```
sizeof(Test)  = 12
  offset b = 0, a = 4, ch1 = 8, ch2 = 9
sizeof(Test2) = 8
  offset a = 0, b = 4, ch1 = 6, ch2 = 7
```

### Условие задачи (вариант 5)

Определить структуру «студент», поля: ФИО, массив элементов структуры «дисциплина» (не менее 4 элементов, результаты сдачи сессии). Структура «дисциплина» включает поля: название, оценка. Задать группу студентов (число студентов вводится с клавиатуры) и определить, **сколько студентов имеют неудовлетворительную оценку по заданному предмету**.

### Решение

- Строки хранятся в `string`, массив студентов и массив дисциплин студента — в `vector` (размер известен только во время работы программы).
- Ввод и вывод одного студента выполняют отдельные функции `inputStudent` и `printStudent`.
- После ввода все данные выводятся для контроля.
- Функция `countFailed` перебирает студентов и их дисциплины и считает студентов, у которых по заданному предмету стоит 2.

### Недостаток такого представления данных

Все студенты одной группы сдают одинаковые дисциплины, но название каждой дисциплины хранится у каждого студента заново. Из-за этого:

- данные дублируются и занимают лишнюю память;
- при вводе легко ошибиться в названии («Math» и «math» программа считает разными предметами), и такой студент не будет учтён при поиске;
- ничто не гарантирует, что у всех студентов одинаковый набор и порядок дисциплин.

**Способы устранения:** хранить список дисциплин один раз для всей группы (например, в структуре «группа»), а у студента хранить только массив оценок, где индекс оценки соответствует номеру дисциплины в общем списке. Предмет для поиска тогда удобно выбирать по номеру из списка, а не вводить названием.
